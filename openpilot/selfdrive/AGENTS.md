# selfdrive/ - DRIVING STACK

Per-frame driving daemons. Stock openpilot core. SP extensions live in [sunnypilot/selfdrive/](file:///Users/cyonsun/Documents/Code/sunnypilot/sunnypilot/selfdrive). See parent [AGENTS.md](file:///Users/cyonsun/Documents/Code/sunnypilot/AGENTS.md) for global conventions.

## STRUCTURE

```
selfdrive/
├── car/             # card daemon - thin Python car interface (uses opendbc/car/)
├── controls/        # controlsd, plannerd, radard + lib/ (lat/long MPC, controllers)
├── selfdrived/      # State machine, alert mgmt, events
├── modeld/          # SNPE-based modeld + dmonitoringmodeld (PC fallback)
├── locationd/       # locationd, calibrationd, paramsd, torqued, lagd
├── pandad/          # C++ pandad - USB/SPI bridge to panda firmware
├── monitoring/      # Driver attention monitoring (dmonitoringd)
├── ui/              # Raylib UI - layouts, widgets, onroad, soundd, feedback
├── assets/          # Icons + offroad HTML + sounds
├── debug/           # Manual debug scripts (gitignored from pytest)
└── test/            # Cross-module integration: process_replay, longitudinal_maneuvers, cpp_harness
```

## DAEMON PIPELINE

```
panda(USB) -> pandad(C++) -> card -> [controlsd <- modeld -> plannerd] -> selfdrived -> ui
                                       ^                                       |
                                       +-- locationd <- camerad <- pandad      v
                                                                            soundd, feedbackd
```

Run a single daemon for testing (after `op_activate_venv`):
```bash
python -m openpilot.selfdrive.controls.controlsd
```

## ANTI-PATTERNS (THIS DIR)

- **NEVER edit `modeld/models/generated/`** - regenerated by SCons via tinygrad compile.
- **NEVER edit `locationd/models/generated/`** - regenerated by rednose.
- **NEVER bypass `card`** to read CAN directly in controlsd - always go through cereal `carState`.
- **NEVER touch `selfdrived/helpers.py` excessive actuation checks** - banned ([docs/SAFETY.md](file:///Users/cyonsun/Documents/Code/sunnypilot/docs/SAFETY.md#L39)).
- **NEVER touch `monitoring/`** to disable driver attention - banned.
- **DO NOT add UI features here** - prefer SP screens in [ui/sunnypilot/](file:///Users/cyonsun/Documents/Code/sunnypilot/selfdrive/ui/sunnypilot).
- **DO NOT use `pyray.is_mouse_button_pressed/released`** - use `Widget._handle_mouse_press/release` (lint-banned via TID251).
- **DO NOT include `third_party/raylib/include/raylib.h`** - use `system/ui/raylib/raylib.h` (lint-checked).

## NOTES

- `controlsd_ext.py` (in [sunnypilot/selfdrive/controls/](file:///Users/cyonsun/Documents/Code/sunnypilot/sunnypilot/selfdrive/controls)) wraps the stock `controlsd` to inject MADS, blinker pause, NNLC, lateral overrides.
- `modeld` and SP `modeld_tinygrad` are mutually exclusive at runtime (toggled via `ModelManagerSP.Runner`).
- `assets/icons/` has 61 files - large flat dir; do NOT add per-feature subdirs.
- `ui/translations/` are gettext .ts files - regenerate via SCons; do NOT hand-edit `.qm`.
